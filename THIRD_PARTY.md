# Third-party components

This archive contains application source and dependency manifests. Dependencies and model weights are obtained separately and retain their upstream terms and notices.

| Component | Upstream |
| --- | --- |
| discord.js | https://github.com/discordjs/discord.js |
| Discord voice | https://github.com/discordjs/voice |
| Ollama | https://github.com/ollama/ollama |
| Default chat model | https://ollama.com/library/qwen3:4b-instruct |
| Faster-Whisper | https://github.com/SYSTRAN/faster-whisper |
| Piper | https://github.com/OHF-Voice/piper1-gpl |
| Ryan high model card | https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/ryan/high/MODEL_CARD |
| yt-dlp | https://github.com/yt-dlp/yt-dlp |
| FFmpeg | https://ffmpeg.org/ |

The Ryan high model card lists its training dataset license as CC BY-NC-SA 4.0. Do not assume every voice permits commercial use; review the relevant model card and upstream terms for your intended use. No model weights or music are bundled here.

Additional Node dependencies and recorded license metadata appear in package-lock.json. Python dependencies appear in requirements.txt. This project is not endorsed by Discord, model authors, or music sources.
